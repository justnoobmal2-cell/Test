# 안전게서

비수도권 거주자의 안전권 불평등을 다루는 웹앱입니다. 우리 동네 소방서·경찰서 위치를 지오게서처럼 맞히고, 새 시설이 생기면 좋을 곳에 투표하고, 그 결과를 통계로 모읍니다.

## 실행 방법

- `index.html` 파일 하나로 동작합니다. 브라우저로 열거나 GitHub Pages에 올리면 됩니다.
- 인터넷 연결이 필요합니다. 지도와 시설 위치는 실행할 때 OpenStreetMap에서 불러옵니다.

## 기능

| 탭 | 하는 일 |
| --- | --- |
| 맞히기 | 지도를 우리 동네에 맞추고 시작하면, 화면 안의 소방서·경찰서 중 5문제가 나옵니다. 찍은 곳과 실제 위치 사이의 거리로 점수를 매깁니다. |
| 투표 | 소방/경찰 중 하나를 고르고 지도에서 위치를 찍어 투표합니다. 가장 가까운 기존 시설까지의 거리, 예상 출동 시간, 시군구 이름을 함께 보여 줍니다. |
| 통계 | 지역별 투표 수, 투표 이유, 게임 평균 오차, 데이터로 계산한 사각지대 마을 TOP 5, 시간 안에 닿는 마을 비율을 보여 줍니다. |

## 모둠 통계 모으기

기록은 각자의 기기(브라우저)에만 저장됩니다. 모둠원이 통계 탭에서 **기록 내보내기**로 JSON 파일을 만들고, 한 사람이 **기록 불러와 합치기**로 모두 불러오면 통계가 합쳐집니다. 투표는 **CSV**로도 받을 수 있어서 엑셀로 그래프를 만들 수 있습니다.

## 데이터와 한계

- 시설·마을 위치: OpenStreetMap(Overpass API). 빠진 시설이 있을 수 있습니다.
- 더 정확한 자료가 필요하면 공공데이터포털에서 위도·경도가 있는 시설 CSV를 받아 통계 탭의 **공공데이터 CSV로 시설 바꾸기**로 불러오세요.
- 예상 출동 시간 = 직선거리 × 1.3(도로 우회) ÷ 시속 40km. 실제 도로 사정과 다를 수 있는 **추정값**입니다.
- 사각지대 계산에서 치안센터는 뺐습니다. 상시 출동 거점이 아닌 경우가 많기 때문입니다.
