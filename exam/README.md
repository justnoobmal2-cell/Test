# 단원별 기출 트레이너

평가원·교육청 기출을 **단원별로 분류해 두고, 약한 단원만 골라 푸는** 웹앱.
빌드 도구 없이 `exam/index.html` 을 브라우저로 열면 바로 돌아간다. (GitHub Pages 로 올리면 `/exam/` 경로)

## 왜 만들었나

모의고사는 3월·6월·9월처럼 **회차 단위**로 묶여 있어서, "삼각함수만 30문제" 같은 식으로는 못 푼다.
이 앱은 기출을 `과목 › 선택과목 › 대단원 › 중단원` 으로 쪼개 두고, 원하는 조합만 뽑아 세트를 만들어 준다.

## 기능

| 화면 | 하는 일 |
|---|---|
| 홈 | 진도·정답률·연속 학습일, **약점 집중 10문항** 원터치 시작, 취약 대단원 요약 |
| 문제 풀기 | 과목/선택과목/대단원/중단원/연도/시행/학년/상태로 필터 → 문항 수·순서 정해 세트 생성 |
| 풀이 | 객관식·단답형, 문항별 타이머, 즉시 채점, 해설, 북마크, 키보드 `1~5`/`Enter` |
| 결과 | 점수, 단원별 정답률, 문항별 O/X, **틀린 것만 다시 풀기** |
| 분석 | 대단원별·중단원별·시행별 정답률(낮은 순), 아직 안 푼 단원, 막대 탭 → 그 단원 바로 풀기 |
| 오답노트 | 틀린 문제 / 복습 대상 / 북마크, 문항별 메모 |
| 문제 관리 | 직접 입력, JSON·CSV 가져오기, 백업 내보내기, 검색·삭제 |

**약점 집중** 은 중단원 정답률(낮을수록 ↑), 최근 오답 여부, 미풀이 여부, 복습 시점을 함께 점수화해 뽑는다.
**복습 스케줄** 은 틀린 문제를 즉시, 맞힌 뒤에는 1 → 3 → 7 → 14 → 30일 간격으로 다시 띄운다.

## 문제 데이터 넣기

실제 기출 지문·문항은 저작권이 있어 이 저장소에 담지 않았다. 내장된 16문항은 동작 확인용 자작 샘플이다
(`문제 관리 › 설정 › 샘플 문제 표시` 로 끌 수 있다).

기출은 **문제 관리** 화면에서 넣는다. 세 가지 방법:

1. **직접 입력** — 한 문항씩 폼으로. 단원은 교육과정 목록에서 고르거나 직접 입력.
2. **JSON / CSV 파일 불러오기** — 스프레드시트로 정리해 두고 한 번에.
3. **JSON 붙여넣기**

### JSON

```json
[
  {
    "year": 2025, "exam": "9월", "org": "평가원", "grade": "고3",
    "subject": "수학", "track": "공통",
    "unit": "수학Ⅰ", "topic": "삼각함수",
    "no": 9, "points": 4, "type": "객관식",
    "choices": ["1", "2", "3", "4", "5"],
    "answer": 3, "level": 3,
    "img": "https://.../2025-09-math-09.png",
    "text": "문제 본문(선택)",
    "solution": "해설(선택)"
  }
]
```

### CSV

```csv
id,year,exam,org,grade,subject,track,unit,topic,no,points,type,choices,answer,level,img,text,solution
,2025,9월,평가원,고3,수학,공통,수학Ⅰ,삼각함수,9,4,객관식,"1|2|3|4|5",3,3,,,
```

| 필드 | 설명 |
|---|---|
| `id` | 비우면 자동 생성. 같은 `id` 로 다시 넣으면 덮어쓴다(정답 수정 시 유용) |
| `exam` | `3월` `4월` `5월` `6월` `7월` `9월` `10월` `수능` |
| `org` | 비우면 `exam` 으로 자동(6월·9월·수능 → 평가원) |
| `track` | 선택과목. 공통 범위면 `공통` |
| `unit` / `topic` | 대단원 / 중단원. 교육과정 목록에 없는 이름도 그대로 쓸 수 있다 |
| `type` | `객관식` 이면 `answer` 는 1~5, `단답형` 이면 답 문자열(공백·대소문자 무시하고 채점) |
| `choices` | CSV 에서는 `|` 로 구분. 비우면 ①~⑤ 번호만 표시 |
| `img` | 문제 이미지. **URL 권장** — 파일로 넣으면 브라우저 저장 공간(약 5MB)을 빨리 쓴다 |

지문이 긴 국어·영어는 `text` 대신 `img` 에 캡처 URL 을 넣고, 분류(`unit`/`topic`)와 `answer` 만 정확히 채워도
"이 유형만 골라 풀기 + 정답률 분석"은 그대로 동작한다.

## 데이터 저장 위치

브라우저 `localStorage` 에만 저장된다. 서버로 아무것도 보내지 않는다.
**기기·브라우저를 바꾸기 전에 `문제 관리 › 내보내기(JSON)` 로 백업**할 것. 복원은 같은 화면의 불러오기.

