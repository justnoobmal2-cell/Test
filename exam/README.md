# 단원별 기출 트레이너

기출을 **단원별로 분류해 두고, 약한 단원만 골라 푸는** 웹앱.
빌드 도구 없이 `exam/index.html` 을 열면 바로 돌아간다. (GitHub Pages 로 올리면 `/exam/`)

기본 교육과정은 **2022 개정 / 고1** 기준이며, 통합사회1·2 와 통합과학1·2 의 단원 트리가 들어 있다.

## 왜 만들었나

모의고사·시험지는 3월, 6월, 1학기 중간처럼 **회차 단위**로 묶여 있어서
"화학 변화만 30문제" 같은 식으로는 못 푼다.
이 앱은 문제를 `과목 › 세부 과목 › 대단원 › 중단원 › 소단원` 으로 쪼개 두고,
원하는 조합만 체크해서 세트를 만들어 준다.

## 화면

| 화면 | 하는 일 |
|---|---|
| 홈 | 오늘의 학습(약점 추천 원터치), 진도·정답률·연속 학습일, 밀린 복습/오답, 취약 단원 |
| 문제 선택 | **직접 선택**(단원 체크박스 트리) 또는 **약점 추천**. 조건·상세 조건으로 좁히고 하단에서 바로 시작 |
| 풀이 | 객관식·단답형, 난이도/배점 표시, 문항별 타이머, 즉시 채점, 해설, 북마크, 키보드 `1~5`/`Enter` |
| 결과 | 점수, 단원별 정답률, 문항별 O/X, **틀린 것만 다시 풀기** |
| 분석 | 대단원별·중단원별·시행별 정답률(낮은 순), 아직 안 푼 단원, 막대 탭 → 그 단원만 바로 풀기 |
| 오답노트 | 틀린 문제 / 복습 대상 / 북마크, 문항별 메모 |
| 문제 관리 | 직접 입력, JSON·CSV 가져오기, 백업 내보내기, 검색·삭제, 다크 모드 |

**단원 트리**는 대단원을 체크하면 하위가 전부 선택되고, 일부만 고르면 부모가 `–` 로 표시된다.
각 줄 오른쪽의 개수는 현재 조건에서 그 단원에 걸리는 **문항 수**다.

**약점 추천**은 중단원 정답률(낮을수록 ↑), 최근 오답 여부, 미풀이 여부, 복습 시점 도래를
함께 점수화해 위에서부터 뽑는다. 홈에서 누르면 전 과목, 문제 선택 화면에서 누르면 고른 과목 안에서만 뽑는다.

**복습 스케줄**은 틀린 문제를 즉시, 맞힌 뒤에는 1 → 3 → 7 → 14 → 30일 간격으로 다시 띄운다.

## 문제 데이터 넣기

실제 기출 지문·문항은 저작권이 있어 이 저장소에 담지 않았다.
내장된 20문항은 동작 확인용 자작 샘플이다 (`문제 관리 › 설정 › 샘플 문제 표시` 로 끌 수 있다).

기출은 **문제 관리** 화면에서 넣는다.

1. **시험지 통째로 넣기** ← 회차 단위로 넣을 때는 이게 제일 빠르다 (아래 참고)
2. **직접 입력** — 한 문항씩. 단원은 교육과정 목록에서 고르거나 직접 입력.
3. **JSON / CSV 파일 불러오기** — 스프레드시트로 정리해 두고 한 번에.
4. **JSON 붙여넣기**

### 시험지 통째로 넣기

`문제 관리 › 시험지 통째로 넣기` 에서 시험지 한 회차를 몇 분 만에 넣을 수 있다.

**1단계.** 연도·시행·학년·과목을 한 번만 고르고, **정답표를 붙여넣는다.**
형식은 알아서 읽는다 — `1 ③ 2 ⑤ 3 ①`, 줄바꿈된 `1. 3`, `1)3 2)5`, 동그라미만 나열한 `③⑤①②④` 모두 된다.
단답형이 섞여 있으면 그것도 구분해서 넣는다.
읽을 수 없는 형식이면 **억지로 추측하지 않고 비워 둔다.** 정답표를 잘못 읽는 쪽이 못 읽는 쪽보다 나쁘기 때문이다.

**2단계 (선택).** 시험지 PDF에서 글자를 긁어 **문제 본문**에 붙여넣으면,
문항 번호로 잘라서 각 문항에 넣고 **단원까지 자동으로 추천**한다.
(예: "빅뱅", "주기율표", "중화" 같은 말이 나오면 해당 소단원으로 태깅. 추천된 항목에는 `자동` 배지가 붙는다.)

**3단계.** 문항 목록에서 여러 개를 골라 **한 번에 단원을 지정**한다.
시험지는 보통 단원 순서대로 나오니, `1~5번 = 과학의 기초` 처럼 묶어서 찍으면 30문항도 금방 끝난다.
**사진 일괄 첨부**로 촬영한 이미지를 번호 순서대로 한 번에 붙일 수도 있다.

자동 추천은 어디까지나 추천이라, 저장 전에 한 번 훑어보고 틀린 건 고치면 된다.

### JSON

```json
[
  {
    "year": 2026, "exam": "1학기 중간", "org": "내신", "grade": "고1",
    "subject": "통합과학", "track": "통합과학1",
    "unit": "물질과 규칙성",
    "topic": "물질의 규칙성과 성질",
    "sub": "원소의 주기성",
    "no": 7, "points": 3, "type": "객관식",
    "choices": ["1", "2", "3", "4", "5"],
    "answer": 2, "level": 3,
    "img": "https://.../q7.png",
    "text": "문제 본문(선택)",
    "solution": "해설(선택)"
  }
]
```

### CSV

```csv
id,year,exam,org,grade,subject,track,unit,topic,sub,no,points,type,choices,answer,level,img,text,solution
,2026,1학기 중간,내신,고1,통합과학,통합과학1,물질과 규칙성,물질의 규칙성과 성질,원소의 주기성,7,3,객관식,"1|2|3|4|5",2,3,,,
```

| 필드 | 설명 |
|---|---|
| `id` | 비우면 자동 생성. 같은 `id` 로 다시 넣으면 덮어쓴다(정답 수정 시 유용) |
| `exam` | `1학기 중간` `1학기 기말` `2학기 중간` `2학기 기말` `3월` `5월` `6월` `7월` `9월` `10월` `11월` `수능` |
| `org` | 비우면 `exam` 으로 자동 (내신 / 교육청 / 평가원) |
| `track` | 세부 과목. `통합과학1`, `통합사회2`, `공통수학1` 등 |
| `unit` / `topic` / `sub` | 대단원 / 중단원 / 소단원. 교육과정 목록에 없는 이름도 그대로 쓸 수 있다 |
| `type` | `객관식` 이면 `answer` 는 1~5, `단답형` 이면 답 문자열(공백·대소문자 무시하고 채점) |
| `choices` | CSV 에서는 `\|` 로 구분. 비우면 ①~⑤ 번호만 표시 |
| `level` | 1(하) ~ 5(상) |
| `img` | 문제 이미지. **URL 권장** — 파일로 넣으면 브라우저 저장 공간(약 5MB)을 빨리 쓴다 |

지문이 긴 문제는 `text` 대신 `img` 에 캡처 URL 을 넣고, 분류(`unit`/`topic`/`sub`)와 `answer` 만
정확히 채워도 "이 단원만 골라 풀기 + 정답률 분석"은 그대로 동작한다.

## 교육과정 트리 고치기

`js/curriculum.js` 의 `CURRICULUM` 을 고치면 단원 목록이 바뀐다.
교과서 출판사마다 중단원·소단원 이름이 조금씩 달라서, 학교 진도와 다르면 여기를 손보거나
문제를 넣을 때 단원 이름을 직접 입력하면 된다(입력한 이름은 트리에 자동으로 붙는다).

## 데이터 저장 위치

서버로 아무것도 보내지 않는다. 전부 브라우저 안에만 있다.

- **문제 정보·풀이 기록·단원 분류** → `localStorage`
- **문항 이미지** → `IndexedDB`

문항 이미지는 한 장에 30~100KB라 localStorage(약 5MB)에 넣으면 몇 회차 만에 꽉 찬다.
그래서 이미지는 IndexedDB 에 따로 넣고, 문제의 `img` 값에는 `"idb"` 만 남긴다.
가져오기 할 때 `data:` 로 시작하는 이미지는 자동으로 IndexedDB 로 옮겨진다.
현재 사용량은 `문제 관리 › 백업` 에 표시된다.

**기기·브라우저를 바꾸기 전에 `문제 관리 › 내보내기` 로 백업**할 것.
내보내기는 두 가지다 — *이미지 빼고*(가볍다) / *이미지 포함*(그대로 복원된다).

```
exam/
├── index.html          앱 셸 + 하단 내비
├── css/style.css       라이트/다크 테마
└── js/
    ├── curriculum.js   2022 개정 단원 트리(3단계), 시행·학년·난이도
    ├── data.js         내장 샘플 문항 + 문제 스키마 주석
    ├── autotag.js      정답표 파싱, 본문 분할, 단원 자동 추천

    ├── store.js        localStorage, 풀이 기록, 통계, 복습 스케줄
    └── app.js          화면 렌더 + 액션
```

## 한 파일로 묶기

버전이 꼬이거나 가져오기가 번거로울 때는 통합본을 만들면 된다.

```
node tools/bundle.mjs 기출트레이너.html 문제데이터.json ...
```

`index.html` 이 참조하는 css·js 를 전부 한 파일에 인라인하고, 문제 데이터를 함께 주면
내장 문제로 구워 넣는다. 결과 파일은 **열기만 하면 되고 가져오기가 필요 없다.**
이미지가 HTML 안에 있어 브라우저 저장 공간도 쓰지 않는다(풀이 기록은 그대로 남는다).

내보낸 통합본에는 문제 내용이 들어가므로 **저장소에 커밋하지 말 것.**

## 저작권에 대해

이 저장소에는 **실제 기출 문항이 들어 있지 않고, 앞으로도 넣지 않는다.**
공개 저장소에 올리는 것은 재배포에 해당하기 때문이다.

본인이 가진 시험지·문제집을 본인 기기에 넣어 공부하는 것은 여기에 해당하지 않는다.
앱의 문제 데이터는 전부 사용자의 브라우저 안에만 있고 서버로도 저장소로도 나가지 않는다.
다만 백업 JSON 에는 문항 이미지가 들어갈 수 있으니 **저장소에 커밋하지 말 것.**
